Wer das Tool nutzt

Clip-Finder ist ein privates Programm, das ausschließlich auf dem Rechner des Betreibers läuft und nur für dessen eigene YouTube- und TikTok-Kanäle verwendet wird. Es gibt keinen Server im Internet, keine Nutzerkonten und keine Weitergabe an Dritte.

Welche Daten verwendet werden

  • Anmeldung (OAuth): Bei der Verbindung mit YouTube oder TikTok erhält das Tool einen Zugangsschlüssel. Er wird nur auf dem eigenen Rechner gespeichert und dient allein dazu, Videos hochzuladen.
  • YouTube-Daten: Das Tool lädt Videos auf den ausgewählten Kanal hoch (Titel, Beschreibung, Sichtbarkeit) und liest die Aufrufzahlen der selbst hochgeladenen Videos.
  • TikTok-Daten: Das Tool lädt Videos auf das angemeldete Konto hoch.

Andere Daten der Konten, etwa Kommentare, Abonnenten, Nachrichten oder Kontaktdaten, werden weder gelesen noch gespeichert.

Weitergabe

Daten werden nicht verkauft, nicht weitergegeben und nicht für Werbung genutzt. Sie verlassen den Rechner nur in Richtung der jeweiligen Plattform (YouTube bzw. TikTok), wenn ein Video hochgeladen oder eine Aufrufzahl abgefragt wird.

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use). Für YouTube gelten zusätzlich die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Löschen und Widerruf

Die Verbindung lässt sich jederzeit im Tool mit „Trennen“ beenden; der gespeicherte Zugangsschlüssel wird dabei gelöscht. Zusätzlich kann der Zugriff unter myaccount.google.com/permissions bzw. in den TikTok-Einstellungen widerrufen werden.
